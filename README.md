## 关于我 · About

硕士期间（2020-2023）：
湖南大学电子信息硕士，2023年毕业，研究生阶段以核心成员身份参与自主可控电子束光刻（EBL）仿真 EDA 软件 **HNU-EBL** 的研发，聚焦**邻近效应校正（PEC）算法**。该软件能独立实现电子束散射蒙特卡洛仿真、散射能量沉积计算、快速卷积迭代剂量校正等核心算法模块，使用C++/Python 混合编程的 PC 端软件从算法验证到交付测试的全流程。本人独立完成电子束光刻邻近效应形状矫正、能量沉积计算、利用FFT算法实现快速卷积计算、利用PyQt实现前端界面设计做到可视化结果。

第一段工作，中国联通湖南省分公司（2023.07-2026.08）：
1、售前解决方案：为考试院上云、雪天盐业、建行上云、湘科集团等项目提供技术方案、成本报价与招投标支持，推动多项合作落地。 （个人评价：并未学到什么东西，甚至由于缺少项目没走完过全流程，属于该阶段混日子了，完全没有收获，包括售前流程，货真价实的技术方案都没有，可以忽略）
2、云资源与平台管理：负责全省 3.1 万+终端规模云桌面平台运维与扩容，完成 10 个地市云资源梳理与下线，累计下线虚拟资源 307 个、vCPU 17,217 个、宿主机 130 台，各地市资源下降率达 22.6%。（个人评价：就是根据平台上的资源量，利用率低的就通知总部下线，我只是起到个看资源觉得够用了就下线的这个角色，完全没什么技术，感觉和第一段一样混着玩的）
3、全省云桌面运维：独立承担故障处理、账号开通、镜像制作、策略配置与网络咨询；支撑 3.1 万+终端规模及约 1 万台年度增量，每周处理约 400 台次故障和 50+业务问题（个人评价：这个确实做了点事情，知道了联通云桌面的配置、运行、处理了不少问题，能够在底层敲一些简单的代码Openstack的基本情况，熟悉云桌面各种故障，网络的可能不太了解，虚拟化部分的日常处理的比较多，但是归根到底还是没什么特别的技术，只能处理一些简单的问题，比如重启还原下、缺少XML文件了疏散下，底层敲代码查看下资源情况等等，比前两个好点，但是也没什么用我觉得）

- 🧮 **Algorithm** — 快速卷积迭代、FFT 计算、遗传算法拟合，兼顾校正精度与计算效率
- ⚙️ **Engineering** — C++ / Python 混合编程，Linux 下的功能、性能测试与 PC 端软件交付
