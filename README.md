## 关于我 · About

湖南大学电子信息硕士，研究生阶段以核心成员身份参与自主可控电子束光刻（EBL）仿真 EDA 软件 **HNU-EBL** 的研发，聚焦**邻近效应校正（PEC）算法**。
习惯在 Linux 下用 Python / C++ 把论文里的算法写成能跑、能复现的代码。

- 🔬 **Research** — 邻近效应校正（PEC）、电子散射蒙特卡洛仿真、散射能量沉积计算、剂量与形状混合校正
- 🧮 **Algorithm** — 快速卷积迭代、FFT 计算、遗传算法拟合，兼顾校正精度与计算效率
- ⚙️ **Engineering** — C++ / Python 混合编程，Linux 下的功能、性能测试与 PC 端软件交付
- 🌱 **Interest** — 开源与算法研究，乐于把实验性想法整理成可复用的代码
- 💼 **Now** — 中国联通（湖南）· 云计算解决方案 / 运维工程师（阿里云 ACP 认证）
- 🔗 **Project** — [HNU-EBL · www.ebeam.com.cn](https://www.ebeam.com.cn)
